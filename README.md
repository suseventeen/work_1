# 新闻标题文本处理实验

学生时期“网络内容安全第一次实验”的 Python 练习，作为历史学习记录保留。

## 内容

main.py 调用 work_function.py，对 News_Final.csv 的前 1,000 行、第 3 列文本执行分词、英文词过滤、小写转换、停用词过滤、Porter 词干化及词典和权重输出。

依赖 pandas、jieba、nltk。原环境包含 Python 3.7、pandas 0.25.1 和 numpy 1.17.2；原仓库未提供 jieba 和 nltk 的确切版本。

## 运行

创建并激活虚拟环境后，从仓库根目录执行：

```sh
python -m pip install -r requirements.txt
python main.py
```

News_Final.csv 已保留在本仓库，现有结果保留在 Output/。脚本覆盖同名输出。依赖清单未锁定版本，尚未验证当前环境的运行兼容性。

## 数据与计算限制

- 原仓库未注明 News_Final.csv 的来源或许可；本次不对来源作推断。
- 名为 df 的统计量实际累计词的出现次数，不能直接理解为文档频率。
- fw 是代码中定义的词频与上述计数的比值，并非标准 TF-IDF。
